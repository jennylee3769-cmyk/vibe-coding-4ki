홍보 영상 브리프 복사

hyperframes 스킬로 내 전자책 홍보 영상을 만들어 줘.

- 목적 : 전자책 「책 제목」 소개, 소개 페이지 방문 유도

- 대상 : 기획서의 독자 한 문장

- 길이 · 비율 : 45 초, 세로 9:16 (1080×1920) 먼저

- 톤 : 차분하고 신뢰감 있게, 내레이션 없이 화면 글자 중심

- 재료 : 이 폴더의 표지.png, 사진.jpg

- 핵심 3가지 : 1. … 2. … 3. …

- 핵심 숫자 : 첫 달 7만원 (이 숫자만, 지어내지 말 것)

- 구조 : 훅 → 문제 → 해결 3가지 → 숫자 증거 → 표지 + 링크 안내

스토리보드를 먼저 보여 주고, 렌더는 내가 승인한 뒤에 해 줘.

질문이 오면 하나씩 답하기. 모르면 추천 옵션 번호로 선택
