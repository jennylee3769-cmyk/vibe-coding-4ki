렌더해 줘

hyperframes 스킬로 내 전자책 홍보 영상을 만들어 줘.
- 목적 : 전자책 「책 제목」 소개, 소개 페이지 방문 유도
- 대상 : 기획서의 독자 한 문장
- 길이 · 비율 : 45 초, 세로 9:16 (1080×1920) 먼저
- 톤 : 차분하고 신뢰감 있게, 내레이션 없이 화면 글자 중심
- 재료 : 이 폴더의 표지.png, 사진.jpg
- 핵심 3가지 : 1. … 2. … 3. …
- 핵심 숫자 : 첫 달 7만원 (이 숫자만, 지어내지 말 것)
- 구조 : 훅 → 문제 → 해결 3가지 → 숫자 증거 → 표지 + 링크 안내
스토리보드를 먼저 보여 주고, 렌더는 내가 승인한 뒤에 해 줘.

3번 장면 글자를 반으로 줄여 줘. 5번은 숫자 카운트업으로. 나머지는 그대로.

· 0~3초 훅 글자 1.5배, 등장 더 빠르게.
· 12초 장면 너무 길어. 4초로 줄이고 뒤 장면 당겨 줘.
· 숫자 카운트업 끝나고 1초 멈춤 추가.
· 전환은 모두 컷으로. 와이프는 해결 구간 시작에만.
· 배경색을 표지의 남색 계열로 통일.
· 마지막 표지 장면 3초 → 4초.

미리보기 열어 줘

미리보기 확인했어. check 통과했는지 확인하고 draft 품질로 렌더해 줘. 파일명은 홍보_세로_
이름.mp4

괜찮아. 같은 설정으로 delivery 품질 최종 렌더해 줘. 파일 크기와 길이도 알려 줘.

같은 스토리보드로 가로 16:9 (1920×1080) 버전도 만들어 줘. 글자 배치만 가로에 맞게 다시.
미리보기 확인 후 렌더할게.

가로 영상을 웹 배경용으로 줄여 줘. ffmpeg로 H.264 MP4, 소리 없이, 5MB 이하 목표. 넘으
면 crf를 올리거나 720p로. 파일명 hero.mp4, 첫 화면은 poster.jpg로 저장하고 용량 알려
줘.

이 폴더에 전자책 소개 페이지를 index.html 한 파일로 만들어 줘. 영상 · 이미지는 같은 폴더 파
일을 상대 경로로.
- 히어로 : hero.mp4 배경 영상 (autoplay muted loop playsinline, poster="poster.jpg")
위에 훅 「훅 문장」 + 「전자책 받기」 버튼
- 화면 폭 768px 미만이면 영상 대신 poster.jpg
- 섹션 : 전자책 소개(핵심 3가지, 표지.png) → 목차 5장 → 저자(사진.jpg) → 구매 · 다운로드
버튼( 링크) → 후기
- 색 : 표지.png 주요 색 2가지 + 흰 배경, 휴대폰 먼저(반응형)
- 공유 미리보기 : og:title, og:description, og:image(표지.png)

접근성을 보완해 줘. 나머지 디자인은 그대로.
- 히어로 영상에 일시정지 / 재생 버튼 (키보드로도 조작, aria-label 포함)
- 동작 줄이기 설정(prefers-reduced-motion)이면 영상 대신 poster.jpg
- 영상 위 글자 뒤에 반투명 어두운 층, 글자 대비 4.5:1 이상
- 영상 안 글자는 본문에도 텍스트로
- 버튼 최소 44×44px

첫 화면 글자 더 크게, 버튼은 표지의 주황색으로.

주소가 「https://... 」로 정해졌어. og:image와 og:url을 이 주소 기준 전체 경로로 바꿔 줘. 바꾼 폴더는 다시 끌어다 놓을게.
