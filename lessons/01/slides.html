기획서 템플릿 프롬프트

주제 "고른 주제"로 콘텐츠 기획서 1장을 만들어 줘.
아래 8개 항목을 표로 정리해 줘.
1. 제목 (후보 3개)
2. 한 줄 소개 (독자가 얻는 것 중심)
3. 독자 (나이, 상황, 고민 한 문장)
4. 독자의 고민 3가지
5. 이 책의 약속 (읽고 나면 할 수 있는 것 3가지)
6. 목차 초안 (5장, 각 장 소제목 3개)
7. 내 경험이 들어갈 지점 (장별로 1개)
8. 파생 콘텐츠 (PPT 10장 구성 아이디어 / 60초 영상 훅 문장 1개)
존댓말, 전문 용어는 풀어서. 결과만 바로 보여 줘.

수정 지시 예시

독자를 "퇴근 후 2시간 남는 40대 직장인"으로 좁혀서 2, 3, 4번만 다시 써 줘. 나머지는 그대로.

실습 환경 설치 프롬프트

내 컴퓨터에 바이브 코딩 4기 실습 환경을 설치해 줘.
운영체제를 먼저 확인하고, 이미 있는 것은 건너뛰어 줘.
Windows는 winget, Mac은 Homebrew를 써 줘.
1. Node.js 22 이상 (LTS)
2. Python 3.12 이상 + pymupdf, markdown-it-py, python-pptx
3. Typst 0.14 이상
4. Playwright 전역 설치 + Chromium
5. FFmpeg
6. 스킬 설치
npx skills add gongnyang/bookforge -g -a codex -y --copy
npx skills add heygen-com/hyperframes -g -a codex -y --copy -s "*"
7. 환경 변수 PYTHONUTF8=1 설정 (한글 깨짐 방지)
끝나면 항목별 설치 여부와 버전을 표로 보여 줘.
