디자인 분석 프롬프트

예시 폴더의 sample-a .pptx 와 .pdf 는 내가 본뜨려는 디자인 예시야.
1. python-pptx로 PPTX를 열어 장마다 배경색, 도형 색, 글꼴 이름, 글자 크기, 위치 · 여백 값
을 뽑아 줘
2. pymupdf로 PDF를 열어 페이지 구성을 확인해 줘
3. design.md 로 정리해 줘. 항목: 색(HEX) / 폰트 / 크기 / 여백 / 레이아웃 패턴(장 유형별) /
강조 방식 / 하지 말 것
4. 내용(부업 이야기)은 빼고 규칙만. 로고 · 사진 · 문구는 가져오지 마

수정 프롬프트

바뀐 부분만 보여 주고 저장해 줘.

구성안 프롬프트

내전자책.pdf 를 pymupdf로 읽고 발표자료 구성안을 만들어 줘.
- 발표 상황 : 강의 / 제안 / 유튜브 설명, 발표 시간 : 10분 → 10 장
- 틀 : 표지 → 청중의 문제 → 약속 3가지 → 핵심 3개(각 1장) → 사례 → 방법 요약 → 지금 할
일 → 마무리
- 각 장 : 제목(결론 한 줄, 20자 이내) / 본문(구절 3개 이내, 60자 이내) / 레이아웃 패턴
(design.md 의 패턴 이름) / 시각 요소 / 화자 스크립트(30~40초, 말하듯이)
- 책 문장을 그대로 옮기지 말고 구절로 줄여 줘
구성안.md 로 저장해 줘.

P P T X 생성 프롬프트

구성안.md 와 design.md 대로 PPTX 를 만들어 줘.
- python-pptx 사용, 16:9 (13.333 × 7.5 인치)
- 모든 글자는 편집 가능한 텍스트 상자로 (통이미지 금지)
- 글꼴 이름 직접 지정 : 제목 나눔명조 / 본문 맑은 고딕, 한글 글꼴(동아시아 글꼴)까지
- 도식은 도형으로, 숫자 차트는 실제 차트 개체로
- 장마다 발표자 노트에 화자 스크립트
- 제목 20자 · 본문 60자 넘으면 줄여서
PPT_ 이름_1020.pptx 로 저장하고 장별 제목 목록을 보여 줘.
